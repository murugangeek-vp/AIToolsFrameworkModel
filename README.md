# AI Stack Explorer 2026 (Version 2)
> The Enterprise AI Engineering Intelligence Platform

AI Stack Explorer 2026 is an executive-grade enterprise AI ecosystem analytics, benchmarking, governance, architecture recommendation, and MLOps intelligence platform. 

This platform enables CTOs, AI Architects, and Engineering Managers to evaluate, compare, benchmark, and design modern AI ecosystems with data-driven operational intelligence.

---

## 🌟 Key Modules

### 1. Data Analytics Ecosystem
- **BI Tools:** metabase, Power BI, Tableau, Superset, Looker.
- **Dashboard Platforms:** Grafana, Kibana, Retool, Streamlit.
- **SQL Engines:** ClickHouse, DuckDB, Trino, Dremio, Snowflake.

### 2. Data Science Ecosystem
- **Notebook Platforms:** Jupyter Notebooks, Google Colaboratory, Posit.
- **Experiment Tracking:** MLflow Tracking, Weights & Biases, Neptune.ai.
- **Visualization Libraries:** Plotly, Matplotlib, Seaborn, D3.js.

### 3. Machine Learning Ecosystem
- **ML Frameworks:** PyTorch, Scikit-learn, TensorFlow, JAX, HuggingFace.
- **ML Algorithms:** Gradient boosting (XGBoost, LightGBM, CatBoost), Supervised classification & regression, Unsupervised clustering (K-Means).
- **Recommendation Systems:** TensorFlow Recommenders, LightFM.
- **Time Series Tools:** Prophet, sktime, statsmodels.

### 4. AI SDLC & MLOps
- **AI SDLC Tools:** GitHub Copilot, ZenML, Kubeflow, Kedro.

### 5. AI Infrastructure

- **Inference Engines & GPU Clouds:** vLLM, TensorRT-LLM, Ollama, Nvidia DGX.

### 6. AI Evaluation & Safety

### 7. Enterprise Governance

## 🚀 Advanced Features

### ⚖️ Tuning Weights & Leaderboard
Adjust sliders for 12 scoring metrics (Enterprise Readiness, Governance, Security, Cost Efficiency, Scalability, Latency, AI Trust, Observability, Community, Ecosystem, Developer Experience, Production Reliability) to dynamically recalculate overall ratings and reorder leaderboards instantly.

### 🧬 AI Architecture Copilot
Specify operational constraints (Scale, Budget, Cloud Host, Compliance, OS preference, Latency limits) and generate a complete **Architecture Blueprint Stack** mapping LLM, Vector Database, Orchestrator, Observability, serving runtime, Evaluation tools, and Governance lineage. Renders a flowing interactive stack pipeline diagram.

### 📊 10 Premium Executive Dashboards
High-fidelity recharts dashboards:
- *AI Trends, Enterprise Readiness, Cost Optimization, Latency Benchmark, AI Security, Enterprise Adoption, Governance & Risk, Open Source vs Paid, Vendor Landscape, Ecosystem Growth.*

### 📤 Custom Dataset Uploader
Drag and drop your own custom CSV datasets. The system runs schema validations and appends custom tools to the store in real-time.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Run

1. Clone the project and navigate to the directory:
   ```bash
   cd AIToolsFrameworkModel
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Compile check:
   ```bash
   npm run build
   ```
